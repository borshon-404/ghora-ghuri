- Bootstrap 5.3.3 (`assets/vendor/bootstrap.min.css`) - MIT, [getbootstrap.com](https://getbootstrap.com) - present but not linked by default.
- Leaflet 1.9.4 (`assets/vendor/leaflet.js`, `leaflet.css`) - BSD-2-Clause, [leafletjs.com](https://leafletjs.com).
- jsPDF 2.5.2 (`assets/vendor/jspdf.umd.min.js`) - MIT, [jspdf.com](https://jspdf.com).
- Map tiles for the Leaflet fallback come from OpenStreetMap tile servers (ODbL, © OpenStreetMap contributors) and require network access; offline builds fall back to the generated coordinate map.

Fonts: Hind Siliguri and Noto Sans Bengali (SIL Open Font License) for Bangla, and the system UI stack elsewhere; see `assets/css/main.css`. If you add a webfont file, keep the licence text alongside it.
